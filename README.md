# MusicLook 音乐视界

> 音频频谱可视化引擎 | Audio Spectrum Visualizer

一个基于 Web Audio API 和 Canvas 2D 的音频频谱可视化工具。单 HTML 文件，即开即用，无需安装任何依赖。

A single-file HTML audio spectrum visualizer powered by Web Audio API and Canvas 2D. Zero dependencies, just open and play.

## 🎮 可视化模式

| 模式 | 预览 | 说明 |
|------|------|------|
| **频谱** (Spectrum) | — | 28 个音符柱体 (C2-B5)，带峰值保持白线、弹簧物理动画 |
| **环形** (Ring) | — | 频谱围绕中心放射状排列，外端连接形成环带，中心留空 |
| **波形** (Waveform) | — | 实时时域波形曲线，带渐变填充 |

## 🚀 使用方法

### 直接使用

用浏览器打开 `musiclook_v1.2.html` 即可运行。

### 准备音频

1. **本地上传** — 点击首页「上传音频」或直接拖拽 MP3/WAV/FLAC 文件到窗口
2. **麦克风输入** — 点击「捕获麦克风/系统」按钮，允许浏览器访问麦克风
3. **Windows 立体声混音**（捕获系统声音）：
   - 右键任务栏音量图标 → 声音设置
   - 进入「录制」选项卡
   - 启用 **立体声混音 (Stereo Mix)**
   - 点击 MusicLook 的麦克风按钮即可捕获系统正在播放的任何声音

### 本地服务器（可选）

```bash
python -m http.server 8766
# 打开 http://localhost:8766
```

## 🔧 技术栈

| 技术 | 用途 |
|------|------|
| Web Audio API | 音频分析 (AnalyserNode, fftSize: 8192) |
| Canvas 2D | 所有渲染 (双 Canvas: 主渲染 + 静态星空) |
| CSS 自定义属性 | 主题系统（动态切换 CSS 变量） |
| Font Awesome 6.5 | 图标 |
| Google Fonts | Orbitron + Noto Sans SC |

- 单文件架构：无构建工具，无 npm，无框架
- 28 个音符映射 (C2-B5)，弹簧物理动画模拟
- 峰值保持系统，缓慢衰减
- 环境粒子 + 爆裂粒子系统
- 毛玻璃面板 UI（主题选择、模式切换）
